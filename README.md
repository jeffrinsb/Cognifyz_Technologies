# 📊 Investment Analysis Project

## 📌 Repository Overview  
This project is part of the **Cognifyz Technologies - Business Analytics Internship** and focuses on analyzing investment patterns, preferences, and key financial insights using **Python (Pandas, Matplotlib, Seaborn)**. The dataset includes details on investment choices, durations, savings objectives, and sources of information.

## 🎯 Objectives  
The goal is to perform **data-driven analysis** to extract meaningful insights, visualize trends, and understand investor behavior using statistical and machine learning techniques.

---

## 📂 Dataset Overview  
The dataset consists of multiple columns that represent investor demographics, investment preferences, sources of financial information, reasons for investments, and expected returns.

### 🔹 **Key Columns in the Dataset**  
- `gender` – Investor's gender  
- `age` – Age of the investor  
- `Investment_Avenues` – Different investment choices  
- `Duration` – Investment duration  
- `Expect` – Investor's expected returns  
- `Reason_Equity`, `Reason_Mutual`, `Reason_Bonds`, `Reason_FD` – Reasons for choosing specific investment types  
- `Source` – Source of financial information  

---

## 🏆 Key Insights  
✔ **Gender Distribution:** Analyzed and visualized investor demographics to understand gender-based investment patterns.  
✔ **Most Preferred Investment Avenue:** Identified the top investment choices using frequency analysis.  
✔ **Reasons for Investment:** Summarized why investors prefer different investment types.  
✔ **Savings Objectives:** Extracted and categorized the most common savings goals.  
✔ **Investment Duration:** Calculated the average duration investors hold their assets.  
✔ **Correlation Analysis:** Explored relationships between investor age, investment duration, and expected returns.
